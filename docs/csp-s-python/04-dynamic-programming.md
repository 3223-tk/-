# 04：动态规划

## 本节目标

能从题目中定义状态、写出转移、确定初始值和计算顺序，并用小样例检查状态含义。

## 动态规划四步

1. **定义状态**：`dp[i]` 或 `dp[i][j]` 到底表示什么？
2. **写转移**：最后一步可能从哪些更小的状态转移过来？
3. **设初值**：最小规模、不可达状态分别是什么？
4. **定顺序**：计算当前状态时，它依赖的状态是否已经算好？

先用一句完整的话描述状态。若说不清 `dp[i]` 的意义，先不要急着写代码。

## 方法清单

### 线性 DP

例如每次可以走 1 阶或 2 阶，`dp[i]` 表示走到第 `i` 阶的方案数：

```text
dp[i] = dp[i - 1] + dp[i - 2]
```

需要根据题目修改初值，并确认是否要对某个数取模。

### 0/1 背包

每件物品最多选一次。`dp[c]` 表示容量不超过 `c` 时的最大价值。处理每件物品时，容量要从大到小遍历，避免同一件物品被重复使用：

```text
for 每件物品 (weight, value):
    for c 从 capacity 到 weight（递减）:
        dp[c] = max(dp[c], dp[c - weight] + value)
```

### 完全背包

每种物品可以选任意次。容量通常从小到大遍历，让当前物品可以在本轮重复使用。0/1 背包与完全背包的循环方向不同，原因是状态是否允许重复使用当前物品。

### 最长上升子序列（LIS）

简单 \(O(n^2)\) 做法中，`dp[i]` 表示以 `a[i]` 结尾的最长严格上升子序列长度：

```text
dp[i] = 1 + max(dp[j])，其中 j < i 且 a[j] < a[i]
```

先掌握这个定义和转移，再学习用二分优化到 \(O(n\log n)\)。

## 练习题

### 1. 爬台阶

共 `n` 阶，每次走 1 阶或 2 阶。求走到顶端的方案数，对 `1_000_000_007` 取模。

- 建议：`dp[i]` 表示到第 `i` 阶的方案数。
- 重点：单独检查 `n=1`、`n=2`。
- 复杂度目标：\(O(n)\)。

### 2. 不相邻的最大和

给定一排整数，可以选择若干个数，但不能选择相邻位置。求能得到的最大和；允许一个数也不选。

- 建议：`dp[i]` 表示只考虑前 `i` 个数时的最大和。
- 转移思考：第 `i` 个数不选，或选择它并跳过前一个。
- 重点：数组中可能有负数。

### 3. 背包选物品

有 `n` 件物品，每件有重量和价值，每件最多选择一次。背包容量为 `C`，求总重量不超过 `C` 时的最大总价值。

- 建议：0/1 背包，容量倒序更新。
- 数据建议：`n <= 300`，`C <= 2 * 10^4`。
- 复杂度目标：\(O(nC)\)。

### 4. 最长上升子序列

给定整数序列，求严格递增子序列的最大长度。子序列可以删除任意元素，但剩余元素相对顺序不变。

- 建议：先写 \(O(n^2)\) DP，再尝试用二分优化。
- 重点：子序列不要求连续。

## 完成本节的标准

- 写代码前能解释每个 `dp` 项代表什么。
- 能分清 0/1 背包与完全背包的循环方向及原因。
- 能用手算验证初值、转移和答案位置。
