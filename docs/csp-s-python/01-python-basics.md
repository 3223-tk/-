## 方法清单

### 输入与输出

小数据可以使用 `input()`。数据量较大时，可以使用：

```python
import sys

input = sys.stdin.buffer.readline
n = int(input())
values = list(map(int, input().split()))
```

`readline()` 读取一行；`map(int, ...)` 把字符串转换为整数。输出多行结果时，先放入列表，最后用 `"\n".join(...)` 合并，通常比反复打印更合适。

### 常用容器

- `list`：按下标访问、顺序存储。
- `tuple`：适合保存固定的一组值，例如图上的 `(邻居, 边权)`。
- `dict`：键到值的映射，适合计数。
- `set`：快速判断一个元素是否出现过。
- `collections.deque`：适合从队首取出、从队尾加入。
- `heapq`：Python 的最小堆，适合每次取出当前最小值。

遍历图邻居时，`for v, w in graph[u]` 会把元组 `(v, w)` 拆成邻居编号和边权。

### 时间复杂度

- \(O(1)\)：常数次操作。
- \(O(\log n)\)：每一步把搜索范围缩小，例如二分。
- \(O(n)\)：遍历一次数据。
- \(O(n\log n)\)：常见排序复杂度。
- \(O(n^2)\)：两层循环遍历所有数对；当 \(n\) 很大时通常不可行。

复杂度是估算工具，不是精确运行时间。要结合题目限制、Python 实现和评测时限判断。

## 练习题

### 1. 成绩统计

输入整数 `n` 和 `n` 个整数成绩。输出总分、最高分和最低分。

- 建议：用列表保存成绩，分别使用 `sum`、`max`、`min`。
- 重点：确认 `n` 至少为 1，理解输入中的空格和换行。
- 复杂度目标：\(O(n)\)。

### 2. 最常见编号

输入 `n` 个非负整数编号。输出出现次数最多的编号及其次数；若多个编号次数相同，输出编号最小的那个。

- 建议：用字典统计频次，再按“次数优先、编号次之”确定答案。
- 重点：不要假设编号范围很小。
- 复杂度目标：平均 \(O(n)\)。

### 3. 服务窗口

输入 `q` 条操作，每条是 `push x`、`pop` 或 `front`。`pop` 删除队首，`front` 查询队首；队列为空时，`pop` 和 `front` 都输出 `EMPTY`。

- 建议：使用 `collections.deque`，不要用列表反复删除第一个元素。
- 重点：处理空队列。
- 复杂度目标：每条操作摊还 \(O(1)\)。
