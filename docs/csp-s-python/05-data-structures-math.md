# 05：数据结构与基础数学

## 本节目标

学会在常见问题中选择合适的数据结构，并掌握竞赛里反复出现的基础数论工具。本节中的树状数组属于进阶必备项，可在前几份文档熟练后学习。

## 方法清单

### 栈与单调栈

栈按“后进先出”处理。括号匹配、撤销操作、单调栈都可以用 Python 列表的 `append` 和 `pop`。

单调栈维护一个单调序列。求每个位置右边第一个更大元素时，从左到右扫描；当当前值比栈顶对应值大，就可以确定栈顶位置的答案。

复杂度通常为 \(O(n)\)：每个元素最多进栈、出栈一次。

### 单调队列

滑动窗口最大值可以用双端队列保存候选下标，并保持对应值从大到小。窗口右移时，移除过期下标；新元素进来时，移除队尾比它小的候选。

复杂度：\(O(n)\)。

### 树状数组（Fenwick Tree）

支持单点增加和前缀和查询；区间和由两个前缀和相减得到。每次操作为 \(O(\log n)\)，适合“边修改边查询”的场景。

和前缀和的区别：前缀和适合数组固定、先建好再查询；树状数组适合数据在查询期间仍会更新。

### 基础数论

- 最大公约数：`math.gcd(a, b)`。
- 质数筛：埃拉托斯特尼筛，预处理 `1..n` 的质数，复杂度约 \(O(n\log\log n)\)。
- 快速幂：重复平方计算 `a^b mod m`，复杂度 \(O(\log b)\)；Python 也可以用 `pow(a, b, m)`。
- 取模：注意题目要求的取模时机，以及负数取模和整除语义。

## 练习题

### 1. 有效括号

给定只包含 `()[]{}` 的字符串，判断括号是否正确匹配。每个左括号都必须由相同类型的右括号按正确顺序闭合。

- 建议：栈；遇到左括号入栈，遇到右括号检查栈顶。
- 重点：空栈时遇到右括号，以及遍历结束后栈非空。

### 2. 右侧第一个更大值

给定数组，对每个位置输出其右侧第一个严格大于它的数；不存在时输出 `-1`。

- 建议：单调栈，栈内保存尚未找到答案的下标。
- 复杂度目标：\(O(n)\)。

### 3. 滑动窗口最大值

给定长度为 `n` 的数组和窗口长度 `k`。对每个连续长度为 `k` 的窗口，输出其中最大值。

- 建议：单调队列保存下标，不要每次重新扫描整个窗口。
- 复杂度目标：\(O(n)\)。

### 4. 动态区间和

初始给定数组，随后有两种操作：`add i x` 将位置 `i` 加上 `x`；`sum l r` 查询闭区间 `[l, r]` 的元素和。

- 建议：树状数组；`sum(l, r) = prefix(r) - prefix(l - 1)`。
- 数据建议：数组长度和操作数均可到 `2 * 10^5`。
- 复杂度目标：每次操作 \(O(\log n)\)。

### 5. 质数个数查询

给定 `q` 个整数 `x`，每次查询 `1..x` 中有多少个质数。

- 建议：先筛到所有查询中的最大 `x`，再做质数前缀计数。
- 重点：1 不是质数，0 也不是质数。
- 复杂度目标：预处理后每次查询 \(O(1)\)。

### 6. 模幂计算

给定非负整数 `a, b` 和正整数 `m`，输出 `a^b mod m`。

- 建议：理解快速幂，再与 Python 的 `pow(a, b, m)` 对照验证。
- 重点：大指数下不要先计算完整的 `a ** b`。
