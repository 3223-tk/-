# 03：搜索与图论

## 本节目标

掌握邻接表、图搜索、并查集和常见最短路；能把“额外使用次数、开关状态”等条件建模成图上的状态。

## 图的存储：邻接表

有 `n` 个点时，可使用：

```python
graph = [[] for _ in range(n + 1)]
```

若点编号是 `1..n`，下标 0 留空。对一条无向边 `(u, v, w)`：

```python
graph[u].append((v, w))
graph[v].append((u, w))
```

`graph[u]` 存从 `u` 直接可走到的邻居。邻接表适合稀疏图，空间复杂度为 \(O(n+m)\)。

## 方法清单

### BFS：无权图最短步数

用队列按距离从近到远访问点。第一次到达某点时，得到的就是从起点到它的最少边数。网格里每移动一次代价相同，也可以使用 BFS。

复杂度：\(O(n+m)\)。

### DFS：遍历与连通块

从一个点出发，反复访问未访问的邻居。可以找连通块、判断是否可达。图很深时用显式栈，避免 Python 递归深度限制。

复杂度：\(O(n+m)\)。

### 并查集

用 `parent[x]` 表示集合代表元，并通过路径压缩和按大小合并，让合并与查询接近常数时间。适合回答“两个点是否连通”和“不断加入边后的连通关系”。

### Dijkstra：非负边权最短路

`dist[u]` 表示从起点到 `u` 的当前最小花费。使用 `heapq` 每次取出当前花费最小的状态，再尝试松弛邻边：

```text
若 dist[u] + w < dist[v]：
    更新 dist[v]
    把新状态放入最小堆
```

堆中可能留有旧记录，弹出时若 `cost != dist[u]` 就跳过。Dijkstra 适用于边权非负的图。

复杂度：\(O((n+m)\log n)\)。

### Kruskal：最小生成树

将边按权值从小到大排序；若一条边连接两个不同并查集，就选它并合并集合。选到 `n-1` 条边后得到最小生成树。若无法选满，图不连通。

复杂度：\(O(m\log m)\)。

### 增加条件：状态也属于点

“最多用一次免费券”时，只知道城市不够，还要知道券是否用过。因此状态写成 `(城市, 是否已用券)`，距离表为：

```python
dist = [[math.inf, math.inf] for _ in range(n + 1)]
dist[1][0] = 0
```

从 `(u, 0)` 沿费用为 `w` 的边到 `v`，有两种转移：

- 正常付费到 `(v, 0)`，花费增加 `w`。
- 用券免费到 `(v, 1)`，花费不变。

从 `(u, 1)` 只能正常付费到 `(v, 1)`。把这些状态照样放进 Dijkstra 的优先队列。答案是 `min(dist[n])`。

## 练习题

### 1. 网格最短路

给定 `n × m` 网格，`.` 表示可走，`#` 表示障碍。从给定起点出发，每步可上下左右移动一格，求到终点最少移动步数；不可达输出 `-1`。

- 建议：BFS，队列存坐标，距离单独记录。
- 数据建议：`n, m <= 1000`。
- 复杂度目标：\(O(nm)\)。

### 2. 道路最短费用

给出 `n` 个城市和 `m` 条非负权双向道路，求城市 1 到城市 `n` 的最低费用；不可达输出 `-1`。

- 建议：邻接表 + Dijkstra + `heapq`。
- 重点：区分 `graph`（道路）和 `dist`（累计最短费用）。
- 复杂度目标：\(O((n+m)\log n)\)。

### 3. 动态连通

开始时 `n` 个点互不相连。接下来有 `q` 个操作：`link u v` 表示连接两个点，`ask u v` 查询两点当前是否连通。

- 建议：并查集。
- 重点：查询操作不能只根据直接相邻边判断。
- 复杂度目标：接近 \(O((n+q)\alpha(n))\)。

### 4. 修路计划

给出若干候选道路及其费用，选择一组道路让所有城市连通且总费用最低；若无法连通输出 `-1`。

- 建议：Kruskal + 并查集。
- 重点：最小生成树不是从某个起点出发的最短路。

### 5. 免费通行券

给定非负权双向图，从城市 1 到城市 `n`，最多选择一条道路免费通过，求最低花费；不可达输出 `-1`。

- 建议：扩展 Dijkstra 状态为 `(城市, 券是否已使用)`。
- 先手算一个小图，再写 `dist[n][0]` 和 `dist[n][1]` 的意义。
- 复杂度目标：\(O((n+m)\log n)\)，状态数是原来的两倍。

## 完成本节的标准

- 能独立写出邻接表、BFS、并查集和普通 Dijkstra。
- 知道 BFS 适用于边数代价相同的最短路，Dijkstra 适用于非负权最短路。
- 能把一个有限状态条件加入节点状态，而不是枚举所有路线。
