## 每个知识点的练习方法

1. 先用自己的话说明：要记录什么状态？每一步如何转移？
2. 手算题目样例，再自己补一个边界样例。
3. 不看答案写代码；运行后检查空输入边界、最小规模、最大规模和不可达情况。
4. 通过后，写下时间复杂度、空间复杂度，以及自己第一次卡住的地方。
5. 隔几天不看旧代码重新写一遍。能独立重写，才算真正掌握。

不要只背模板。先确认题目条件满足算法的前提，例如 Dijkstra 要求边权非负，正数数组上的双指针不能直接照搬到含负数的数组。

## Python 竞赛习惯

- 大量输入时使用 `sys.stdin.buffer.readline`。
- 优先队列使用 `heapq`；队列使用 `collections.deque`。
- 建图前确认点的编号从 0 还是从 1 开始。
- 留意递归深度；深度可能很大的图搜索优先写成显式栈或队列。
- 看到数据范围时先估算复杂度，避免对大输入使用多重全量循环。
