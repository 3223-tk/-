# 02：常用算法技巧

## 本节目标

学会利用输入结构减少重复工作：用前缀和回答区间查询，用双指针处理有序或正数数据，用二分答案寻找最优阈值，用贪心做局部选择。

## 方法清单

### 前缀和

令 `prefix[i]` 表示前 `i` 个数之和，令 `prefix[0] = 0`。若数组下标从 0 开始，闭区间 `[l, r]` 的和为：

```text
prefix[r + 1] - prefix[l]
```

若题目下标从 1 开始，则闭区间 `[l, r]` 的和为 `prefix[r] - prefix[l - 1]`。建立前缀和需要 \(O(n)\)，每次区间查询需要 \(O(1)\)。

### 差分

如果有很多次“给区间 `[l, r]` 每个数加上 `x`”，不要每次逐个修改。对差分数组执行：

```text
diff[l] += x
diff[r + 1] -= x
```

所有操作做完后，对 `diff` 求前缀和，即得到每个位置的总变化量。适合“多次区间修改，最后统一输出”的场景。

### 双指针

两个指针维护一个窗口，满足条件时扩展窗口，不满足时移动左端点。对于**所有元素为正数**的数组，窗口和随右端点增加而不减；移除左端点元素后，窗口和不增，因此可以在线性时间内找满足和限制的最长窗口。

含负数时，窗口和不再单调，不能直接使用这个做法。

### 二分答案

当答案在一个有序范围内，且存在“阈值可行则更大的阈值也可行”或相反的单调性时，可以二分答案：

1. 设定答案上下界。
2. 写 `check(x)` 判断阈值 `x` 是否可行。
3. 利用单调性缩小区间，直到找到边界。

重点不是背二分模板，而是证明 `check` 的结果具有单调性。

### 贪心

贪心是在每一步做一个局部选择。局部最优不一定得到全局最优；必须解释为什么这个选择不会让最优答案变差。常见证明思路是交换论证：若最优方案没有采用该选择，就把它替换成贪心选择，证明结果仍不更差。

## 练习题

### 1. 区间求和

输入长度为 `n` 的数组和 `q` 个查询。每个查询给出 `l, r`，输出闭区间 `[l, r]` 的元素和。约定输入下标从 1 开始。

- 建议：前缀和。
- 数据建议：`n, q <= 2 * 10^5`。
- 复杂度目标：\(O(n+q)\)。

### 2. 和不超过 S 的最长连续段

给定一个**全为正数**的数组和整数 `S`，求元素和不超过 `S` 的最长连续子数组长度。

- 建议：右指针扩展窗口；当窗口和超过 `S` 时移动左指针。
- 数据建议：`n <= 2 * 10^5`。
- 复杂度目标：\(O(n)\)。

### 3. 按顺序装箱

有 `n` 件物品，重量为正整数，必须按给定顺序装入若干箱子；每箱容量相同，每件物品不能拆分。求在最多使用 `k` 个箱子的前提下，箱子容量最小是多少。

- 建议：二分容量；`check(C)` 从左到右装箱，判断容量 `C` 是否够用。
- 重点：证明容量越大，所需箱子数不会增加。
- 复杂度目标：\(O(n\log W)\)，`W` 为重量总和。

### 4. 区间加数

初始有 `n` 个零，随后给出 `q` 个操作，每个操作将闭区间 `[l, r]` 的每个位置加上 `x`。输出全部操作后的数组。

- 建议：差分数组。
- 复杂度目标：\(O(n+q)\)。

### 5. 最多参加的活动

给出若干活动的开始和结束时间。一个人不能同时参加重叠活动，求最多能参加多少个活动。

- 建议：按结束时间排序，每次选择当前能参加且结束最早的活动。
- 重点：说明为什么较早结束能给后续活动留下更多空间。
- 约定：一个活动在时间 `t` 结束、另一个在 `t` 开始时，两者不算重叠。
- 复杂度目标：\(O(n\log n)\)。
